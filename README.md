## 几个核心洞察

### 1. 你以为的心理问题，可能只是身体在喊救命

> 大脑不关心真相，只关心生存。当内部稳态失衡而大脑无法定位来源时，它会**借用外部事件作为解释**——你以为你在为某个人痛苦，其实你只是血糖低了、没睡好、皮质醇飙升了。

关键实验：**Dutton & Aron (1974) 吊桥实验**——男性在摇晃的吊桥上遇到女性研究员，会把心跳加速和手抖**错误归因**为"我爱上了她"。情绪的生理唤醒和认知标签是可以分离的。

### 2. 社会排斥和物理疼痛是同一条神经通路

> Eisenberger (2003) fMRI研究发现，被社会排斥时激活的**前扣带回（ACC）和前脑岛**，和被针扎时激活的区域完全相同。对乙酰氨基酚（泰诺）不仅能治头痛，还能减轻社会性痛苦。

这意味着：孤独不是"心情不好"，孤独是**真实的疼痛**。进化把社会连接变成了和疼痛一样的生存信号——在原始部落中，被排斥=死亡。

### 3. 多巴胺不是快乐，是"想要"

> 多巴胺不负责"喜欢"，负责"想要"。它驱动你去**追逐**，而不是享受。你刷手机刷到停不下来，不是因为快乐，而是因为多巴胺在不断地"预测下一个可能的奖赏"——哪怕那个奖赏根本不存在。

内啡肽才是"休息与奖赏"——跑完步后的runner's high、吃完辣后的愉悦、深度拥抱后的放松，都是内啡肽。

### 4. 一切社会现象，底层都是稳态

> 被责骂→ACC激活→威胁信号→皮质醇升高→稳态失衡→身体进入战斗/逃跑模式。
> 被攀比→社会比较→地位焦虑→睾酮/皮质醇波动→稳态失衡。
> 被孤立→社会连接断裂→疼痛矩阵激活→稳态失衡。

**没有什么"纯心理"的东西。一切都在身体里有对应的物理变化。**

### 5. 文明是进化策略的群体放大

> 道德不是"天理"，是**互惠利他的群体契约**；宗教不是"迷信"，是**用超自然信念强化群体凝聚力的进化工具**；国家不是"必然"，是**大规模合作的博弈均衡**；消费主义不是"选择"，是**多巴胺劫持+社会地位信号的完美陷阱**。

挖到最底层，文明的每一块砖，都是身体里的一次激素分泌。
